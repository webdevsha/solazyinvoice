Objektif Pembelajaran

Aplikasi Dunia Nyata

Contoh Sistem Alumni:

Dalam modul ini, kita akan membina Profil Awam & Halaman Portfolio. Ini membolehkan alumni mempamerkan Projek Tahun Akhir (FYP) dan portfolio kreatif mereka kepada bakal majikan dalam susun atur grid yang menarik secara visual.

Modul 2: Logik Backend, Pangkalan Data & Pengujian

Fasa Pelaksanaan & Validasi

Objektif Pembelajaran

  • • Anda akan Membangunkan skema pangkalan data untuk menyimpan butiran FYP dan rekod alumni.
  • • Anda akan Mengesahkan integriti data menggunakan Ujian Unit (Unit Testing).
  • • Anda akan Merancang logik Panel Admin untuk meluluskan pendaftaran alumni baharu.

Aplikasi Dunia Nyata

Contoh Sistem Alumni:

Kita akan membina Papan Pemuka Admin & Lapisan Logik. Ini mengendalikan data di belakang tabir—memastikan apabila alumni menghantar projek FYP baharu, ia disimpan dengan betul dalam pangkalan data dan memerlukan kelulusan admin sebelum muncul di frontend.
